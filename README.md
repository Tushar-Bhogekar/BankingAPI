# 🏦 Scalable Banking API (.NET)

## 🚀 Overview

A secure and scalable backend banking system built using **ASP.NET Core Web API**, supporting core banking operations such as account management, beneficiary handling, and fund transfers.

Designed with clean architecture principles, this project focuses on performance, security, and real-world banking workflows.

---

## ⚙️ Tech Stack

* **Backend:** ASP.NET Core Web API (.NET 8)
* **Language:** C#
* **Database:** SQL Server
* **ORM:** Entity Framework Core
* **Authentication:** JWT (JSON Web Token)
* **API Style:** RESTful APIs

---

## 🔥 Key Features

* 🔐 Secure authentication & authorization using JWT
* 💳 Account creation and management
* 👥 Beneficiary management
* 💸 Fund transfer functionality with validation
* 📩 Email notifications for transactions (SMTP integration)
* ⚡ Optimized database queries for better performance
* 🧱 Modular and scalable API architecture

---

## 🧠 System Design Highlights

* Followed **Clean Architecture principles**
* Separation of concerns (Controllers, Services, Repositories)
* Efficient handling of transactions and data consistency
* RESTful API design for seamless frontend integration

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/scalable-banking-api-dotnet.git
```

2. Navigate to project

```bash
cd scalable-banking-api-dotnet
```

3. Update database connection string in `appsettings.json`

4. Run migrations

```bash
dotnet ef database update
```

5. Run the application

```bash
dotnet run
```
